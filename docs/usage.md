# 摄像头与日常使用

先完成[安装](getting-started.md)并登录管理页面。xcos 管理实例、媒体状态和服务端录像；摄像头地址及密码由 xcoc 客户端保存。

## 添加一台摄像头

1. 在实例管理中新建一个客户端实例，取得授权码。
2. 在摄像头所在网络安装 xcoc，输入服务端 HTTPS 根地址和授权码。
3. 在 xcoc 配置 RTSP、ONVIF、本地或手机摄像头，选择录像位置。
4. 回到管理页，确认实例快照更新并打开实时画面。

一实例对应一台摄像机。具体命令见 [xcoc 平台指南](https://github.com/isarmg/xcoc/blob/main/docs/platform-setup.md)。

## 看懂摄像头状态

- 有效观测：最近一次 MediaMTX 路径清单读取成功，按页面显示查看在线状态。
- 观测已过期：保留上次状态供比较，先检查媒体服务及网络。
- 尚无有效观测：等待第一次成功观测，或按[排障指南](troubleshooting.md)检查。
- 已停用：按设备配置显示停用状态。

详情页同时列出最后有效媒体观测时间和 Client 上报的设备状态。客户端在线、媒体路径在线与可播放画面需分别核对。

## 播放与云台

选择摄像头和可用主/子码流，打开实时播放。浏览器通过短期授权访问 WHEP/HLS。
支持 ONVIF 云台的设备显示相应能力；执行后检查实际画面。动作显示未确认时，先核对实际设备位置与操作记录，再决定是否发出新动作。

## 查看录像

服务端录像模式在管理页选择当前实例下的录像设备，查询时间范围并打开片段。改变实例或查询后重新选择片段。
客户端录像模式的 MP4 保存在 xcoc 主机，不会自动变成服务端历史录像。配置为录像只说明配置生效，还需确认片段持续生成。

## 查看日志与账号

日志页按服务器本地日期查询单日或日期范围，包含起止两天。使用首页、上一页和下一页查看事件、媒体协调操作和业务审计。
记录错误时间、实例 ID 和操作 ID 后再排查，避免把过期页面当作最新状态。

管理员从右上角人物图标进入[账号设置](account-settings.md)。管理员密码、实例授权码和媒体密钥分别管理；修改一种凭据只按对应流程操作。
