# 修改当前账号

登录管理 Web 后，点击上方菜单栏最右侧的圆形人物图标，输入账号名称和当前密码。需要修改密码时填写并确认新密码；留空则保留原密码。点击“保存账号”后，使用新账号信息重新登录，其他浏览器的旧会话也会失效。

账号名称是登录用户名，不会改变内部账号 ID、Sentinel Client 实例或摄像头归属。此入口只修改当前登录账号；系统仅允许一个管理员，不提供创建管理员入口。

实例名称在详情页修改，允许 1–64 个 Unicode 字符，首尾按 Unicode White_Space 裁剪；控制字符会被拒绝。实例名称与管理员登录用户名是不同字段。

并发请求按实际活跃时间维护会话；正常空闲到期和显式注销后需要重新登录。

账号改名不改变稳定的内部账号 ID。Server 只接受当前 Schema；账号设置不执行数据库升级或迁移。
