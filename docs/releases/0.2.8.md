# Sentinel Monitor Server 0.2.8

Sentinel is now the Server side of a multi-brand camera platform. It receives normalized device identity, capabilities, main/sub streams, health, and command results from paired edge Clients, and exposes unified live video and PTZ control without storing vendor camera credentials.

Each instance uses an encrypted renewable authorization code. The administrator can select Server or Client recording storage, remove cancelled unpaired instances, and use the shared list/detail/configuration/log workspace.
