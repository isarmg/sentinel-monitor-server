# sentinel-monitor-server 0.2.21

- 管理 Web 的“日志”页按服务器本地日期显示事件、媒体操作和审计记录，默认服务器当天，可选择日期，一次显示所选日全部记录。夏令时日期边界和每条记录的 UTC 偏移均按服务器时区计算。单组日志响应上限为 64 MiB，浏览器请求时限为 120 秒。
- 事件实时快照与历史日志查询分别处理。日志重试错误不会被实时通知覆盖；重新进入页面时重新取得服务器当天，切换日期时取消过时请求。
- 实例表单和录像选择随当前实例、摄像头列表保持一致，避免旧选择和旧查询结果出现在新视图。
- 部署及加密文档按当前实现说明 `CREDENTIALS_KEY` 的密文认证，不再声称存在独立的 key ID。

## 验证

- Rust 测试、严格 Clippy、Web 构建及 Chromium / Firefox 浏览器验收通过；日志验收覆盖大量记录、跨时区和夏令时日期。
