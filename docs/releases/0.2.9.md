# Sentinel Monitor Server 0.2.9

The Server and administrator Web now consume Foundation 0.7.11 directly from the locked Rust and npm packages, with duplicated Platform Router and Web Shell source snapshots removed.

Native lifecycle operations are unified behind the single public `sentinelctl` command. Bootstrap, start, status, and stop implementations are private non-executable action modules, and release verification enforces the new layout and permissions.

Build metadata derives and tests the exact Foundation revision from `Cargo.lock`; ONVIF parsing also handles the Foundation streaming-error contract explicitly.
