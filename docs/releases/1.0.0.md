# xcos 1.0.0 发行说明与包内入口

软件版本为 `1.0.0`。程序、数据库结构、设备协议和媒体依赖分别标识；判断包内容时以完整源码 SHA、程序身份和 manifest 为准。
公开 v1.0.0 归档早于当前 `xcos-db-v2` 实现。本源码中的说明描述当前构建输入，不表示已有同名标签附件包含后续代码。

## 当前源码能力

- Rust 控制面管理摄像头实例、实时播放、录像查询、媒体操作和审计。
- 独立 xcoc 保存摄像头凭据，并向固定 MediaMTX 1.20.0 发布媒体。
- 管理页面嵌入服务端，公共支撑为 xcss 1.0.2 和一个构建期 `@xcss/web` 包。
- 当前数据库身份 `xcos-db-v2`、结构修订 2；浏览器身份 `xcos-wire-v2`，设备协议 `xcos-edge-v1`。

## 安装本归档

使用 Linux AMD64 GNU 主机和全新安装目录。归档包含 `opt/` 发行树及许可证；主机配置、数据库和录像位于树外。
先核对同版归档摘要，然后从归档所在目录执行：

```sh
sha256sum --check SHA256SUMS
sudo tar -xzf xcos-1.0.0-x86_64-unknown-linux-gnu.tar.gz \
  -C / --keep-old-files --no-overwrite-dir opt
sudo /opt/isarmg/xcos/releases/1.0.0/deploy/xcosctl bootstrap
sudoedit /etc/isarmg/xcos.env
```

审阅管理员密码、独立 JWT Secret 与 Credential Key，填写客户端可达的公开 RTSPS 地址、受信任证书和私钥。
将相应源码的 `deploy/Caddyfile` 站点纳入主机 HTTPS 配置，限制后端与媒体管理端口访问。加密密钥保持与当前数据匹配。

```sh
sudo /opt/isarmg/xcos/releases/1.0.0/deploy/xcosctl bootstrap --confirm-config
sudo /opt/isarmg/xcos/releases/1.0.0/deploy/xcosctl start
sudo /opt/isarmg/xcos/releases/1.0.0/deploy/xcosctl status
```

确认配置时显式初始化全新状态；已有状态只校验。普通启动运行当前状态。成功后通过 HTTPS 登录，创建实例，在 xcoc 配对并验证画面和新录像。
停止使用同一目录下的 `xcosctl stop`。归档和安装器保持已有发行树不被覆盖。
